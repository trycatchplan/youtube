# Welcome to TryCatchPlan
Simple app to browse the *.wav and *.jpg file(s) in the ./media/ folder. Requires three (3) buttons - one for "Up", one for "OK", and one for "Start" - though D/L/R, Select, and A (Back) have stub functions.
```
python3 -m venv .
source bin/activate
pip install -r requirements.txt
```
And normally it's just...
```
source bin/activate
python app.py
```
Have a glorious day!
